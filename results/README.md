# Results Directory

This directory contains evaluation results from the trading system.

> **2026-08-13 audit note:** the `regime_performance.png` / `ablation.png` / `confidence_curve.png` /
> `equity_curve_after_costs.png` files previously here were generated by `generate_results_plots.py`
> from hardcoded numbers (not a real run) and have been removed. `metrics.csv` previously did not
> exist despite being documented below as `make eval`'s output — `make eval` (`validate_strategy.py`)
> was never actually wired to produce it, and this directory's own `.gitignore` rule (`results/*.csv`)
> would have blocked committing it even if it had been. See the main
> [README's Reproducibility section](../README.md#-reproducibility-audit-2026-08-13) for the full
> story. The files that ARE here now (`metrics.csv`, `walk_forward_folds.csv`, `run_manifest.json`)
> are real, produced by `scripts/run_real_pipeline.py` on 2026-08-13, not by `make eval`.

## Current Files (real, 2026-08-13)

- `metrics.csv` - real measured overall + per-regime metrics (accuracy, AUROC, F1, precision at
  confidence, backtest PnL/win-rate/trades)
- `walk_forward_folds.csv` - real per-fold metrics from the 4-fold walk-forward run
- `run_manifest.json` - full run parameters (seed, date range, walk-forward config, costs) and
  results in one file

## Regenerating

```bash
# Replay from the committed frozen sample, no network needed (~15s)
python ../scripts/replay_from_sample.py

# Or re-fetch fresh data and re-run everything (~5-8 min)
python ../scripts/run_real_pipeline.py
```

## Notes

- Results are generated with a fixed seed (42) for the model, but re-fetching fresh Binance data
  will naturally change the measured numbers run to run
- The PnL/backtest metrics include transaction costs (0.10% fee + 0.05% slippage, per side) — see
  the README for an important caveat about how the neutral-zone filtering affects this backtest's
  trade tape
- `generate_results_plots.py` still exists in the repo root but now carries a warning header; it
  regenerates the OLD, hardcoded-number plots and should not be used to represent real results
